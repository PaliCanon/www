This repository: the showcase at palicanon.app. It presents the PaliCanon
services and links to their own sites (search.palicanon.app,
learn.palicanon.app, the Tipiṭaka iPhone app); it holds no search and no
service. Leptos on `PaliCanon/ui-lib` (by tag), generated as static pages,
Astro-like navigation (view transitions). The copy is the user's: Markdown
under `content/<lang>/`, never rewritten by an agent (an agent may fix the
front matter's syntax and says so). Definition: task `.task/001`, viewer
session `www-001-showcase`.
