# Mentions légales

## Éditeur

palicanon.app est publié par Thibault Rivière, pour le projet PaliCanon, un projet gratuit et non commercial. Contact : riviere.thibault@icloud.com.

## Hébergement

Le site est servi depuis un serveur exploité par l’éditeur lui-même, derrière Cloudflare, Inc. (États-Unis), qui fournit le nom de domaine, le proxy réseau et le tunnel vers ce serveur.

## Vie privée

PaliCanon n’a pas de comptes, ni publicité, ni pistage par des tiers. Les sites gardent quelques préférences (langue, thème, …) dans des cookies et dans le stockage de votre navigateur, et conservent 30 jours ce qui est recherché, sans aucun identifiant. Cloudflare, qui se trouve devant les sites, voit chaque requête. Pour la liste complète et le détail, voir la page [Confidentialité](/fr/privacy/).

### Learn : synchroniser sa progression avec Google Drive

Les utilisateurs de Learn peuvent optionnellement synchroniser leur progression avec leur propre Google Drive. Cette synchronisation ne se fait que lorsque vous vous connectez avec Google. L'accès est limité à un dossier caché (`drive.appdata`) que seul PaliCanon peut consulter. Votre progression est stockée dans ce dossier au même format que la fonction Exporter.

Le script de connexion de Google n’est chargé que lorsque vous ouvrez la synchronisation. L’adresse e-mail du compte est mémorisée dans le stockage de votre navigateur (`pc_learn_sync`) pour vous la proposer à la prochaine connexion. Votre jeton de connexion Google est conservé dans la mémoire de votre navigateur (sur le site) ou dans la chaîne de clés macOS (sur l'application), jamais sur les serveurs de PaliCanon. PaliCanon n'a pas de copie côté serveur de votre jeton ou de vos données. Se déconnecter supprime l'accès quand le jeton est toujours stocké. Sur l'application, le jeton est toujours stocké. Sur le site, le jeton est stocké seulement jusqu'au rechargement de la page. Vous pouvez supprimer l'accès à tout moment sur https://myaccount.google.com/connections.

La politique de confidentialité de Google s'applique à la façon dont Google traite vos données. Selon les exigences d'utilisation limitée de Google, les données des API Google ne sont utilisées que pour fournir cette fonction de synchronisation.
